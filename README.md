# Facebook Reel Downloader — Netlify

1. Upload/push these files to GitHub.
2. Import the repository into Netlify.
3. Keep the publish directory as `public`.
4. In Netlify Environment Variables add:
   `RAPIDAPI_KEY` = your NEW RapidAPI key.
5. Deploy/redeploy.

Never put the RapidAPI key in `index.html` or GitHub.
